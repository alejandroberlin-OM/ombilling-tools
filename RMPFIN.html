What this does
And the few things worth knowing about the numbers.
The three headline figures
FigureMeans
Total submittedThe sum of the Submitted column for that provider's claim lines
Total paidWhat has actually been paid so far
OutstandingStill owing. Can be negative on a line where a payment was reversed
Why there is sometimes a "written off" line. Submitted = paid + written off + outstanding. A write-off is usually a few cents, so it is shown on the totals block only when it is not zero — but when it is there, leaving it out would make the three figures not add up.
Collected is paid ÷ submitted, and nothing more. The report's own "Billing Success" percentage measures something different and is deliberately not reproduced here: a provider can read 96% on one and 42% on the other in the same month, simply because most of the claims have not been adjudicated yet, and two percentages that disagree on the same page invite the wrong question.
On the PDFs
  • Landscape letter, table scaled to fill the printable width.
  • Rows run in service-date order, then patient, then code.
  • The column header repeats at the top of every page.
  • A long service description is shortened with an ellipsis; nothing else is ever cut — a long patient name is set in a smaller size instead.
  • No row is highlighted and no counts are tallied under the totals: the Status column says what it says, line by line.
  • The last page explains the explanatory codes that appear on that provider's claims, in the Ministry's own wording. A code with no description on file prints as the bare code rather than a guess, and the Codes tab says which ones those are.
If the export changes
Columns are matched by their heading rather than by position, so a column moving sideways is handled. If a heading is renamed or removed, the Review tab says which one could not be found instead of silently producing a blank column, and the totals are cross-checked against the footer the report prints for itself.
