What this does
Replaces the three-macro routine end to end:
1. Builds every CabMD column from the source sheet.
2. Maps each written diagnosis to an OHIP 3-digit code.
3. Splits A343 Z292-style rows into one line per code — the step that used to be manual.
4. Adds a K301A line for every Virtual, Phone visit.
5. Normalises dates to MM/DD/YYYY and appends the trailing A to service codes.
Diagnosis Mapping
Each written diagnosis is matched to the closest OHIP 3-digit code. Override any of them — your choices are remembered for next time.
